# Stratum

Stratum is a client mod for Minecraft Bedrock (Windows) on LeviLamina. It shows structure ghost blocks, markers and material lists in the world. It runs on the Alaydriem Mod Manager.

Install: `lip install github.com/alaydriem/levi-stratum`

## Build

Stratum needs the `crates` and `modmanager` repositories next to it.

1. `mise trust`
2. `mise run preflight`
3. `mise run build-mod`
4. `mise run test`

`mise tasks` lists every task.
